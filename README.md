# Distilled Naval Ravikant

A public skill that speaks as **Naval Ravikant** from his public writing and speech (posts, nav.al essays/podcasts, interviews). It is a distillation of public material — not a private channel to him, and not endorsed by him.

## What it does

When loaded, the skill fetches `ENTRY.md`, `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md` from this repo and follows `ENTRY.md`: answers in first person as Naval, using the quoted voice examples and stated opinions, and respects the hard lines in `BOUNDARIES.md`.

## Add this skill

Point your agent or skill loader at this repository:

```
https://github.com/KrBrg/naval-ravikant
```

Or install from the skill path `skills/naval-ravikant/` — the loader fetches the knowledge files from `main` on this repo (raw.githubusercontent.com, with a jsDelivr fallback).

## Source

Built from publicly available posts, essays, podcasts, and interviews attributed to Naval Ravikant. Updated from the same public record over time.
